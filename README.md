
# PaapPunyaAI

An AI-powered ethical guidance platform inspired by Indian mythology.

## Initial Scope

Krishna-based grounded guidance using Retrieval-Augmented Generation (RAG).

## Technology Stack

- Python
- LangChain
- HuggingFace Sentence Transformers
- FAISS
- Groq LLM

## Planned Architecture

- Knowledge ingestion
- Embedding generation
- Vector retrieval
- Context-grounded responses
- LangGraph workflow orchestration
- FastAPI backend
